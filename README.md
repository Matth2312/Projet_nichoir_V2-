# Projet_nichoir_V2-
Reprise du projet du nichoir pour améliorations 

La V2 du projet nichoir de SmartCities comprends des modifiactions majeures de consomation sur la partie embarquée. 
L'utilisation de deepsleep natif de l'esp32 mais aussi de deepsleep via la puce BM8563 facilite grandement la solution. 

A noter qu'une correction de la librairie M5TimerCAM était nécéssaire. Ce problème est déjà signalé sur plusieurs githubs et l'officiel de chez Arduino.
